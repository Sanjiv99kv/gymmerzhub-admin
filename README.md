# GymmerzHub · Ops Console

Platform admin console for GymmerzHub — manage gyms, members, content templates, subscriptions, and payouts.

## Stack

- React 19 + Vite
- TanStack Router + TanStack Query
- Tailwind CSS v4

## Scripts

```bash
npm install
npm run dev
npm run build
npm run preview
```

Dev server defaults to `http://localhost:5173`.
